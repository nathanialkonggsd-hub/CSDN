## 📚 专栏结构

每个目录对应 CSDN 的一个专栏；**文章编号是全局发布时间序号**。

因此，同一篇文章可以属于多个专栏。例如 24 号文章同时归属于「工具」与「Qt开发」，这是有意的跨专栏归档，不视为重复文件。

```text
CSDN文章/
├── C语言/
├── 数据结构/
├── Qt开发/
├── 工具/
├── mcu/
├── vibe coding/
└── 创作历程/
```
