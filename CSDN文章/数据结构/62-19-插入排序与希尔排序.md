## 二、插入排序

### 2.1 思想

> 💡 像**打扑克牌**，每次摸到新牌，插入到手牌的正确位置

### 2.2 代码实现

```c
void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

## 三、希尔排序

### 3.1 思想

> 💡 **分组插入排序**，逐步缩小间隔，最后进行一次插入排序

### 3.2 代码实现

```c
void shellSort(int arr[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j;
            for (j = i; j >= gap && arr[j - gap] > temp; j -= gap) {
                arr[j] = arr[j - gap];
            }
            arr[j] = temp;
        }
    }
}
```

## 四、复杂度对比

| 算法 | 最好 | 最坏 | 平均 | 稳定性 |

| 插入 | O(n) | O(n²) | O(n²) | ✅ |
| 希尔 | O(nlogn) | O(n²) | O(n^1.3) | ❌ |
