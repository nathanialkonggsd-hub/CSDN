## 二、冒泡排序

### 2.1 思想

> 💡 相邻元素比较，如果逆序就交换，每轮把最大的"冒泡"到最后

### 2.2 图解

```mermaid
graph LR
    A["[5,3,8,1]"] -->|"第1轮"| B["[3,5,1,8]"]
    B -->|"第2轮"| C["[3,1,5,8]"]
    C -->|"第3轮"| D["[1,3,5,8]"]
    style D fill:#4CAF50,color:#fff
```

### 2.3 代码实现

```c
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;  // 优化：没有交换说明已有序
    }
}
```

## 三、选择排序

### 3.1 思想

> 💡 每次从未排序部分选最小的，放到已排序部分末尾

### 3.2 图解

```mermaid
graph LR
    A["[5,3,8,1]"] -->|"选最小1"| B["[1,3,8,5]"]
    B -->|"选最小3"| C["[1,3,8,5]"]
    C -->|"选最小5"| D["[1,3,5,8]"]
    style D fill:#4CAF50,color:#fff
```

### 3.3 代码实现

```c
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        if (minIdx != i) {
            int temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }
}
```

## 四、复杂度对比

| 算法 | 最好 | 最坏 | 平均 | 空间 | 稳定性 |
|:----:|:----:|:----:|:----:|:----:|:----:|
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ |

**稳定性**：相同值的元素排序后相对位置不变
