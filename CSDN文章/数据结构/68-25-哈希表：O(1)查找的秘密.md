## 二、哈希表基本概念

### 2.1 什么是哈希表？

> **哈希表**：通过**哈希函数**将键映射到数组下标，实现快速查找

```
key → 哈希函数 → 下标 → 存储值
```

### 2.2 哈希函数

```c
int hash(int key, int size) {
    return key % size;
}

int hashString(char *str, int size) {
    unsigned long hash = 5381;
    while (*str) {
        hash = ((hash << 5) + hash) + (*str++);
    }
    return hash % size;
}
```

## 三、冲突解决

### 3.1 什么是冲突？

> 不同的key经过哈希函数得到**相同的下标**

```
key1=5, key2=15, size=10
hash(5)=5, hash(15)=5  冲突！
```

### 3.2 链地址法

> 💡 冲突的位置用**链表**存储

```c
typedef struct Node {
    int key;
    int value;
    struct Node *next;
} Node;

typedef struct {
    Node **buckets;
    int size;
} HashTable;

HashTable* createTable(int size) {
    HashTable *table = (HashTable*)malloc(sizeof(HashTable));
    table->size = size;
    table->buckets = (Node**)calloc(size, sizeof(Node*));
    return table;
}

void insert(HashTable *table, int key, int value) {
    int index = key % table->size;
    Node *newNode = (Node*)malloc(sizeof(Node));
    newNode->key = key;
    newNode->value = value;
    newNode->next = table->buckets[index];
    table->buckets[index] = newNode;
}

int search(HashTable *table, int key) {
    int index = key % table->size;
    Node *current = table->buckets[index];
    while (current) {
        if (current->key == key)
            return current->value;
        current = current->next;
    }
    return -1;
}
```

### 3.3 开放定址法

> 💡 冲突时**探测下一个空位**

```c
// 线性探测
int linearProbe(HashTable *table, int key) {
    int index = key % table->size;
    while (table->buckets[index] != NULL) {
        index = (index + 1) % table->size;
    }
    return index;
}

// 二次探测
int quadraticProbe(HashTable *table, int key, int i) {
    int index = (key + i * i) % table->size;
    return index;
}
```

## 四、装填因子

> **装填因子 α = 已存元素数 / 表长**

- α越大，冲突越多
- 一般控制在0.7-0.8
- 超过阈值需要**扩容**
