## 二、并查集基本概念

### 2.1 什么是并查集？

> **并查集**：处理**不相交集合**的合并与查询

两个核心操作：
- **Find**：查找元素所属集合
- **Union**：合并两个集合

### 2.2 基本实现

```c
int parent[MAX];

void init(int n) {
    for (int i = 0; i < n; i++) {
        parent[i] = i;
    }
}

int find(int x) {
    while (parent[x] != x) {
        x = parent[x];
    }
    return x;
}

void union(int x, int y) {
    int px = find(x);
    int py = find(y);
    parent[px] = py;
}
```

## 三、优化

### 3.1 路径压缩

> 💡 查找时，将路径上的节点直接挂到根节点

```c
int find(int x) {
    if (parent[x] != x) {
        parent[x] = find(parent[x]);
    }
    return parent[x];
}
```

### 3.2 按秩合并

> 💡 将矮树挂到高树下面

```c
int rank[MAX];

void init(int n) {
    for (int i = 0; i < n; i++) {
        parent[i] = i;
        rank[i] = 0;
    }
}

void union(int x, int y) {
    int px = find(x), py = find(y);
    if (px == py) return;
    if (rank[px] < rank[py]) {
        parent[px] = py;
    } else if (rank[px] > rank[py]) {
        parent[py] = px;
    } else {
        parent[py] = px;
        rank[px]++;
    }
}
```

## 四、复杂度分析

| 操作 | 未优化 | 路径压缩+按秩合并 |
|:----:|:----:|:----:|
| Find | O(n) | O(α(n))* |
| Union | O(n) | O(α(n)) |

*α(n)是反阿克曼函数，增长极慢，可视为常数

### 5.2 岛屿数量

```c
int numIslands(int grid[][N]) {
    int n = m = N;
    init(n * m);
    
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (grid[i][j] == 1) {
                // 合并相邻的1
                if (i > 0 && grid[i-1][j] == 1)
                    union(i*m+j, (i-1)*m+j);
                if (j > 0 && grid[i][j-1] == 1)
                    union(i*m+j, i*m+j-1);
            }
        }
    }
    
    // 统计根节点数量
    int count = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (grid[i][j] == 1 && parent[i*m+j] == i*m+j)
                count++;
        }
    }
    return count;
}
```
