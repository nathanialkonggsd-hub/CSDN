## 四、成就：我写过最满意的一段 C++ 代码

在过去的创作与实践中，我始终追求**代码的安全性、内存管理的严谨性以及极致的运行效率**。下面是我重构并长期使用的一个符合 RAII 原则且具备强异常安全性的通用动态数组（Dynamic Sequential List / Safe Vector）的核心实现：

```cpp
#include <iostream>
#include <initializer_list>
#include <stdexcept>
#include <algorithm>
#include <utility>

/**
 * @brief 符合 RAII 原则的通用动态顺序表 (Safe Vector Implementation)
 * @tparam T 元素类型
 */
template <typename T>
class DynamicArray {
private:
    T* data_;           // 动态内存指针
    size_t capacity_;   // 当前分配容量
    size_t size_;       // 当前有效元素个数

    // 动态扩容机制（指数级增长）
    void reallocate(size_t new_capacity) {
        T* new_data = new T[new_capacity];
        for (size_t i = 0; i < size_; ++i) {
            new_data[i] = std::move(data_[i]); // 优先移动，提升性能
        }
        delete[] data_;
        data_ = new_data;
        capacity_ = new_capacity;
    }

public:
    // 默认构造函数
    explicit DynamicArray(size_t initial_capacity = 4)
        : data_(new T[initial_capacity]), capacity_(initial_capacity), size_(0) {}

    // 初始化列表构造函数
    DynamicArray(std::initializer_list<T> list)
        : data_(new T[list.size()]), capacity_(list.size()), size_(0) {
        for (const auto& item : list) {
            push_back(item);
        }
    }

    // 析构函数（RAII 保证内存自动释放，杜绝泄漏）
    ~DynamicArray() {
        delete[] data_;
    }

    // 深拷贝构造函数
    DynamicArray(const DynamicArray& other)
        : data_(new T[other.capacity_]), capacity_(other.capacity_), size_(other.size_) {
        std::copy(other.data_, other.data_ + size_, data_);
    }

    // 移动构造函数 (避免非必要拷贝)
    DynamicArray(DynamicArray&& other) noexcept
        : data_(other.data_), capacity_(other.capacity_), size_(other.size_) {
        other.data_ = nullptr;
        other.capacity_ = 0;
        other.size_ = 0;
    }

    // 赋值运算符重载 (Copy-and-Swap 惯用法，保证强异常安全性)
    DynamicArray& operator=(DynamicArray other) noexcept {
        swap(other);
        return *this;
    }

    void swap(DynamicArray& other) noexcept {
        using std::swap;
        swap(data_, other.data_);
        swap(capacity_, other.capacity_);
        swap(size_, other.size_);
    }

    // 尾插元素（左值重载）
    void push_back(const T& value) {
        if (size_ == capacity_) {
            reallocate(capacity_ == 0 ? 1 : capacity_ * 2);
        }
        data_[size_++] = value;
    }

    // 尾插元素（右值重载：高效移动语义）
    void push_back(T&& value) {
        if (size_ == capacity_) {
            reallocate(capacity_ == 0 ? 1 : capacity_ * 2);
        }
        data_[size_++] = std::move(value);
    }

    // 随机访问运算符
    T& operator[](size_t index) { return data_[index]; }
    const T& operator[](size_t index) const { return data_[index]; }

    // 带边界检查的安全访问
    T& at(size_t index) {
        if (index >= size_) {
            throw std::out_of_range("DynamicArray: Index out of bounds!");
        }
        return data_[index];
    }

    size_t size() const noexcept { return size_; }
    size_t capacity() const noexcept { return capacity_; }
    bool empty() const noexcept { return size_ == 0; }
};

int main() {
    DynamicArray<int> arr = {10, 20, 30, 40};
    arr.push_back(50);

    std::cout << "Array Size: " << arr.size() << ", Capacity: " << arr.capacity() << "\n";
    std::cout << "Elements: ";
    for (size_t i = 0; i < arr.size(); ++i) {
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

**为什么这段代码对我意义非凡？**
1. **严格的内存生命周期管理**：遵循 RAII 原则，彻底告别野指针与内存泄漏。
2. **现代 C++ 规范**：巧妙运用移动语义（Move Semantics）与 `Copy-and-Swap` 惯用法，兼顾极佳的执行效率与强异常安全性。
3. **高内聚的接口设计**：既保持了底层指针操作的极佳性能，又提供了安全易用的模版类封装。
