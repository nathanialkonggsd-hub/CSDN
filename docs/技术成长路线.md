# 技术成长路线

## 总体路线

```text
创作起步
   ↓
C语言基础
   ↓
指针 / 内存 / 文件 / 编译
   ↓
数据结构与算法
   ↓
VS / VSCode / CMake / GDB
   ↓
Qt 桌面开发
   ↓
51 单片机
   ↓
STM32
   ↓
TinyML / Embedded AI
```

并行成长线：

```text
Vibe Coding
   ↓
AI 辅助编码
   ↓
测试 / TDD / Debug / 重构
   ↓
AI 辅助软件工程
```

## 阶段一：C语言基础

03–16 是基础能力建立期，覆盖控制流、数组函数、递归、操作符、指针、字符串与内存、整数与浮点数、结构体对齐、动态内存、自定义类型、文件、编译与预处理。

核心意义：从“能写程序”逐渐走向“理解程序如何使用内存、如何被编译”。

## 阶段二：数据结构与算法

17、19 以及 44–70 形成系统的数据结构与算法学习线，覆盖线性结构、树、图、排序、查找和高级结构。

核心意义：建立计算机科学基础，并为 C/C++、嵌入式和软件工程项目提供算法基础。

## 阶段三：工程工具与桌面开发

21、23–31、41–42 逐步形成 VSCode、Debug、Qt Creator、CMake、GDB 和 C/C++ 工具链能力。

24–30 尤其适合继续发展为一个完整的 Qt Mini IDE 项目。

## 阶段四：嵌入式

18、20、22、43 展示从 51 单片机到 STM32 的硬件学习路径。

建议未来以项目驱动学习：GPIO → 定时器 → 中断 → ADC → I2C/SPI/UART → 传感器 → 显示 → 网络通信。

## 阶段五：TinyML / Embedded AI

71 是当前路线中非常重要的升级点：将 STM32、传感器数据和机器学习结合起来。

建议继续形成完整链路：

```text
数据采集 → 数据集 → 预处理 → 模型训练 → 量化 → MCU部署 → 实时推理 → 显示/通信
```

## 阶段六：AI辅助软件工程

25、32–39 记录了从 Vibe Coding 到测试、TDD、重构和工程迭代的实践。

下一步重点不是“让 AI 写更多代码”，而是研究：

- 如何拆分需求
- 如何设计架构
- 如何验证 AI 生成代码
- 如何调试与重构
- 如何用测试约束 AI 迭代
- 如何进行人机协作开发

## 最终能力画像

目标形成：

**C/C++ + 数据结构算法 + 工程工具 + Qt + STM32 + TinyML / Embedded AI + AI辅助开发**

其中“项目”负责证明工程能力，“文章”负责证明学习过程与技术思考。
