# 项目路线

> 目标：把已有文章从“知识记录”进一步转化为“可运行、可展示、可复用的工程资产”。

## 项目一：C语言工程化项目

**来源：** 05、32–38 等相关学习内容。

方向：在已有 C 项目基础上继续工程化。

建议能力：

- 模块化设计
- CMake / Makefile
- 数据持久化
- 单元测试
- Debug
- 文档与版本管理

## 项目二：Qt Mini IDE

**来源：** 24、26–30。

建议逐步形成：

```text
编辑器
├── 多标签页
├── 文件树
├── 语法高亮
├── 搜索/替换
├── Terminal
├── CMake
├── GDB
├── Git
└── 项目管理
```

目标：从系列文章升级为一个完整桌面开发项目。

## 项目三：数据结构可视化

**来源：** 44–70。

将已经完成的数据结构与算法文章转化为可交互项目：

- 链表：插入、删除、遍历动画
- 树：构建、遍历、搜索
- 排序：动态可视化
- 图：DFS、BFS、Dijkstra、MST
- 哈希表与并查集：操作过程可视化

目标：让理论知识有可运行的工程载体。

## 项目四：STM32 综合项目

**来源：** 18、20、22、43 以及现有硬件学习积累。

建议整合：

```text
STM32
├── MPU6050
├── OLED / TFT
├── UART / I2C / SPI
└── ESP8266
```

目标：完成“传感器采集 → MCU处理 → 本地显示 → 无线通信”的完整闭环。

## 项目五：STM32 + TinyML

**来源：** 71。

这是当前最值得重点打造的代表项目。

推荐最终结构：

```text
MPU6050
   ↓
数据采集
   ↓
数据集
   ↓
预处理
   ↓
TinyML模型
   ↓
量化
   ↓
STM32部署
   ↓
实时推理
   ↓
TFT/OLED显示
   ↓
ESP8266 / 上位机通信
```

目标：形成一个可以放进简历、GitHub 和作品集的 Embedded AI 项目。

## 推荐优先级

| 优先级 | 项目 | 主要价值 |
|---:|---|---|
| 1 | STM32 + TinyML | Embedded AI 代表作 |
| 2 | Qt Mini IDE | 软件工程与桌面开发 |
| 3 | STM32 综合项目 | 嵌入式系统能力 |
| 4 | 数据结构可视化 | CS基础与算法能力 |
| 5 | C语言工程化项目 | 基础与工程规范 |

原则：**一次只推进一个主项目，文章围绕项目产生，项目反过来验证文章中的知识。**
