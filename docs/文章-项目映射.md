**定位：当前旗舰项目 🔥**

形成一个可以真实运行、测试、展示和持续迭代的 Embedded AI 项目。

### 当前阶段

**第一阶段：已跑通基础闭环。**

**第二阶段：正在进入数据集与模型泛化优化。**

### 第二阶段关注点

- 扩充每类样本数量

- 比较模型大小、RAM / Flash、推理时间
- 重新部署 STM32 并进行真实设备测试

### 当前原则

> **先把项目做好，再把项目写好。**

没有真实实验结果，就不为了文章编号提前制造结论。

## 📌 项目化原则

1. **项目进度优先于文章进度。**
2. **文章记录真实过程，不提前编造实验结果。**
3. **每篇项目文章至少对应一个真实产出。**
4. **一篇文章可以服务多个项目，不重复堆砌知识。**
5. **一个项目要有代码、实验数据、测试结果和版本迭代。**
6. **优先完善少数高质量项目，而不是无限增加文章数量。**
