## 4. STM32 综合项目

**目标：** 将现有 MCU 学习与硬件积累整合成一个真正的嵌入式综合项目。

### 文章支撑

- 18：单片机入门
- 20：普中 51 开发板
- 22：GPIO/电平等基础实践
- 43：从 51 到 STM32
- 71：STM32 + TinyML 手势识别

### 项目方向

可以逐步组合：

```text
STM32
├── 传感器：MPU6050
├── 显示：OLED / TFT
├── 通信：ESP8266
├── 输入：按键 / 触摸
└── 软件：驱动层 → 应用层 → 通信层 → UI
```

### 项目价值

这个项目最适合体现“软硬件结合”。不要一次性堆硬件，而是采用模块化迭代，每增加一个模块就形成一次可验证的版本。

### 文章支撑

这个项目可以作为未来简历、GitHub 首页和面试讲解的核心项目之一。

## 项目化原则

1. **文章记录过程，项目承载成果。**
2. **一篇文章可以服务多个项目，不需要复制知识体系。**
3. **一个项目应当有明确的目标、架构、版本迭代、测试和最终演示。**
4. **优先完善少数高质量项目，而不是继续无限增加文章数量。**
5. **每完成一个项目，再反向补充一篇“项目总结/技术复盘”，形成闭环。**
